# Country flags

4:3 SVG flags from [flag-icons](https://flagicons.lipis.dev) 7.5.0 (MIT,
see `LICENSE`), limited to the countries in `ihds/seed/countries.json`.
File name = lowercase ISO 3166-1 alpha-2 code (the `flag` field of an IHDS
country entry). Served as static files, no CDN, so the app works offline.
